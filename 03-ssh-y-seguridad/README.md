# Acceso por SSH con claves y protección básica

**Estado:** pendiente

## Objetivo

Administrar el servidor desde otro equipo por SSH con claves en lugar de contraseñas, y aplicar medidas básicas de seguridad.

## Qué quiero conseguir

- Conexión por SSH con clave pública.
- Acceso por contraseña desactivado.
- Fail2ban para bloquear intentos de acceso repetidos.
- Cortafuegos básico.
