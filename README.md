## Cómo documento cada proyecto

Uso la plantilla de [`plantillas/README-proyecto.md`](plantillas/README-proyecto.md):

1. **Qué es** y por qué lo hago.
2. **Cómo lo hice**, paso a paso.
3. **Qué se rompió** y cómo lo arreglé.
4. **Resultado.**
5. **Qué aprendí.**

## Norma
